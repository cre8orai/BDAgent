# Session log

One file per working session, newest at the top of the table. The point is that anyone —
or any future AI session — can see what was done, what was decided, and what was left
hanging, without reading the whole repo diff.

Name files `YYYY-MM-DD-NN-short-slug.md`.

| Date | Session | Focus | Outcome |
|---|---|---|---|
| 2026-09-03 | [01](2026-09-03-01-repo-setup-and-retail-gtm.md) | Repo setup + retail GTM scaffold | Repo created and pushed; GTM strategy drafted; browser control installed |

## What goes in one

- **Done** — what actually changed, with paths.
- **Decided** — choices made and the reason, especially ones that close off alternatives.
- **Open** — what's unresolved, and who owns it.
- **Next** — the specific next action.

Keep it short. If it takes more than five minutes to write, it's too long.
