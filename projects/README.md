# Projects

Each subfolder is a self-contained body of business development work.

| Project | Status | Description |
|---|---|---|
| [`retail-gtm`](retail-gtm/) | 🟡 Scaffolded | Indirect go-to-market: selling through agencies, licensors, and merch aggregators who build product lines for their own clients. |

## Structure convention

New projects follow the same shape:

```
00-brief/      charter, scope, the model being proposed
01-research/   what's true, with sources
02-strategy/   what we decided to do about it
03-playbooks/  how the team executes
04-artifacts/  published outputs, linked back to source
05-pipeline/   named targets and their state
```
